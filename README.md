# 交換DM作成ツール

X上のオタク取引で使う DM 文章を、テンプレの組み合わせで作るためのツール。

## 現在のスコープ

下タブバーで 3 画面を切り替え（DM作成 ／ 定型文 ／ 設定）。

### DM作成（`#/`）

- 上部は「現在：〜 ／ 変更する ▾」の折りたたみ行。開くと「プリセット」chip が並ぶ
  - プリセットは要素の ON/OFF ＋ テンプレ選択 ＋ 交換内容欄ON/OFF をまとめて適用する仕組み（旧「シーン」機能はここに統合済み）
  - 初回起動時に「郵送交換／現地交換／仮約束（予約品）／譲渡／買取」の5件を自動投入（`src/defaultPresets.ts`）。以後は普通のプリセットとして編集・削除できる
  - 「＋ 現在の内容を保存」で今の状態をプリセット化（名前はインライン入力欄）。設定 →「プリセット」からも新規作成・ON/OFF編集ができる（そちらはテンプレ選択までは変えられない。テンプレを変えたいときは DM作成でセットして保存し直す）
  - 手動でいじると「カスタム」に戻る
- 挨拶・梱包方法など単純な要素は **1行のコンパクト行**（トグル＋ラベル＋選択）で表示。画面の縦の長さを抑えるため
- **交換内容**：「自分が出すもの」「相手が出すもの」の 2 入力（複数行入力可・改行OK） →
  プレビュー行 `{行頭の語句}{自分}{区切り}{相手}`（既定 `内容：〜 ⇆ 〜`、その場で変更可。行頭の語句も複数行入力可）
  - 各欄に**入力履歴**（欄ごとに独立）。フォーカスでサジェスト表示、**ピン留め**で先頭固定、履歴削除も可
  - 履歴 `dm-tool:exchange-history:v1`、表示形式 `dm-tool:exchange-format:v1`
- 下部プレビューにリアルタイム連結（**要素と要素の間は空行区切り**。各要素内部の改行はそのまま）→ 「コピー」ボタン。コピーすると実際に使われたテンプレの `lastUsedAt` を更新（各カテゴリ一覧やプリセット編集の「（自動・最近使ったもの）」に反映される）
- 作成中の下書きは `localStorage`（`dm-tool:compose-draft:v1`）に自動保存

### 定型文（`#/quick`）

- 取引中〜終了のやりとりで、そのままコピーして使う完成文の一覧
- タイトルタップで編集、「コピー」で本文をクリップボードへ、最近コピー順に並ぶ
- 初回起動時にサンプル 4 件（発送しました／発送ありがとう／受け取りました／取引終了の挨拶）を投入。編集・削除可
- 保存キー `dm-tool:quick-messages:v1`
- **連結**: チェックで複数選択 → 選んだ順に連結。継ぎ目に入れる言葉（例「また、」）を1つだけ指定可
  - 文章そのものの言い回しは自動調整しない（AIを使わない方針のため）。あくまで機械的な連結＋継ぎ目の言葉
  - 選択は一時的（保存されない）
- DM作成の要素組み立てとは別系統

### 設定（`#/settings`）

- **一覧**: プリセット ／ 挨拶 / 梱包方法 / 交換方法 / 支払い方法の提示文 / 住所 / 振込先・PayPay等 / 締めの一言 ／ テーマカラー ／ データの移行
- **プリセット（`#/settings/presets`）**: 一覧・新規作成・編集・削除
  - 編集画面は DM作成と同じ「トグル＋要素名＋テンプレ選択」の行（`.compose-row` を流用）。名前・交換内容の使用・要素ごとの ON/OFF とテンプレ選択をここだけで完結して変更できる
  - テンプレ選択は「（自動・最近使ったもの）」も選べる（`selected[kind] = null`。適用時に一番最近使ったテンプレへ自動で解決される）
- **テーマカラー（`#/settings/theme`）**: 背景・カードの背景・文字・アクセントカラーの 4 色を自由に組み合わせ
  - プリセット数種類（標準／ピンク／ミント／サンセット／ラベンダー／ダーク）＋カラーピッカーと16進コード直接入力
  - 変更は即座に画面全体へ反映（`document.documentElement` の CSS 変数を上書き）
  - 削除ボタンの赤・個人情報の注意色など「意味を持つ色」はテーマ対象外で固定
  - 保存キー `dm-tool:theme:v1`。バックアップ対象
- **各カテゴリ（`#/settings/greeting` など）**: 「← 戻る」ヘッダ ＋ 登録済み一覧 ＋「新規作成」、行タップで編集
- **データの移行（`#/settings/data`）**: エクスポート／インポート
  - 位置づけ: **機種変・ブラウザ変更のときにデータを移すため**の機能。普段の利用では不要（自動保存されるため）
  - エクスポート: テンプレ・プリセット・交換内容の履歴／表示形式・テーマカラーを 1 つの JSON ファイルに書き出し（`app`/`version` 付き）
  - インポート: ファイルを読み込み、現在のデータに **マージ**（同じ ID は取り込みファイル側で上書き）。取り込み後は自動で再読み込み
  - 書き出しファイルには住所・振込先が平文で入る旨を画面に明記
  - スマホではファイル操作がやや手間。本格リリース時は端末間のデータ受け渡し方法（コピペ方式や別手段）を再検討する

画面遷移は URL ハッシュのみ。ブラウザの戻る/進むが効く。

## 技術構成

- Vite + React + TypeScript（strict）
- 状態保存: ブラウザの `localStorage` のみ
- **ネットワーク通信・外部サービス連携は一切なし**（`fetch` 等を使っていない）
- dev サーバは `127.0.0.1` のみで待ち受け（LAN 非公開）
- 公開する場合は `npm run build` した `dist/` を静的ホスティングに置く（構成変更不要）
- 配色は CSS カスタムプロパティ（`--bg`/`--card`/`--text`/`--primary`）で一元管理。
  `--border`/`--muted`/`--primary-soft` などは `color-mix()` でこの 4 色から自動計算するため、
  テーマを変えても個別パーツの色を手直しする必要がない（`color-mix()` は 2023 年以降の主要ブラウザで対応）

## セットアップ

```bash
npm install
npm run dev
```

表示された `http://127.0.0.1:5173` をブラウザで開く。

```bash

```

## データの扱い

- 入力データは開いているブラウザの `localStorage` にのみ保存される。住所・振込先などの個人情報も同様（外部送信なし）。
- 別の端末・別のブラウザには引き継がれない。ブラウザのサイトデータ削除で消える。
- バックアップ・移行は「設定 → データ」のエクスポート／インポートで行う。
- localStorage キーは `src/storageKeys.ts` に集約。

| `src/storage.ts` | `localStorage` フック（安全パース）＋ ID 生成 |
| `src/storageKeys.ts` | localStorage キーの一覧 |
| `src/exchangeHistory.ts` | 交換内容欄の入力履歴フック（自分／相手別、ピン留め） |
| `src/SuggestInput.tsx` | 履歴サジェスト付きテキスト入力 |
| `src/backup.ts` | エクスポート／インポート（検証・マージ・ダウンロード） |
| `src/route.ts` | URL ハッシュだけの最小ルーター（`useRoute` / `navigate` / `hrefFor`） |
| `src/defaultPresets.ts` | 初回起動時に投入する5つのプリセット（旧シーン相当） |
| `src/ComposeScreen.tsx` | DM作成画面（プリセット＋要素選択＋トグル＋プレビュー＋コピー） |
| `src/QuickScreen.tsx` | 定型文の一覧・コピー・登録／編集／削除 |
| `src/theme.ts` | テーマカラーの型・プリセット・`useTheme`（CSS 変数への反映） |
| `src/ThemeScreen.tsx` | テーマカラー設定画面 |
| `src/PresetsScreen.tsx` | プリセットの一覧・新規作成・編集（要素ON/OFF＋テンプレ選択）・削除 |
| `src/Switch.tsx` | 共通トグルスイッチ（DM作成・プリセット編集で使用） |
| `src/DataScreen.tsx` | データ（バックアップ）画面 |
| `src/ConfirmDialog.tsx` | 削除・クリア・取り込みの確認モーダル（`window.confirm` の代替） |
| `src/CategoryList.tsx` | 設定ホーム（メニュー一覧） |
| `src/CategoryScreen.tsx` | 1 カテゴリの一覧＋新規作成／編集フォーム |
| `src/icons.tsx` | インライン SVG アイコン |
| `src/App.tsx` | ルート出し分け＋下タブバー、初回データ投入、データ保持 |
